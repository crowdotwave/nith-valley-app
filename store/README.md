# Store submission drafts

Everything the two stores ask for that is words rather than code. All of it is
a draft for the practice to approve; anything marked **TO CONFIRM** needs an
answer from them before it can be used.

| File | What it is for |
| --- | --- |
| `privacy-policy.md` | The public privacy policy both stores link to. Needs a home on the practice's website. |
| `listing.md` | Store page text: name, subtitle, descriptions, keywords, category, support and privacy links. |
| `data-declarations.md` | Answers for Apple's privacy labels and Google Play's Data safety form. |
| `review-notes.md` | Notes for Apple's and Google's reviewers, including how they get in. |

These describe the app as it will be at submission, so they assume account
deletion and push notifications are built. Update them if either changes
shape.
